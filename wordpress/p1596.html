アイコンフォント

Posted on 2015年3月31日

アイコンフォントの概要

アイコンフォントとはベクトル形式のフォントに文字ではなくアイコンが割り当てられたフォントのことです。アイコンフォントはどんなサイズのデバイスにも柔軟にフィットします。PNGやGIFのようにスケーラブルでないアイコン画像を置き換えることで1つのリソースであらゆるスクリーンサイズに対応することが出来ます。

アイコンフォントには次のようなメリットがあります。

メリット
  • アイコンがスケーラブルでレスポンシブデザインと相性が良い
  • アイコンとテキストの配置をスタイルシートで調整できる
  • アイコンサイズをスタイルシートで調整できる
  • アイコンの色をスタイルシートで調整できる

アイコンイメージがベクトル画像なのでWebのデザインでマルチデバイスをサポートする場合に一つのアイコンフォントファイルでアイコン画像が綺麗にレンダリングできるのでレスポンシブデザインを採用しているWebサイトではアイコンフォントを使用しているサイトが多くなって来ています。

デメリット
  • 一度に使用しないアイコンも含めてすべてのアイコンをロードする
  • アイコンが単色になる

一度に使用しないアイコンも含めてすべてのアイコンをロードする問題

ロード時間を少しでも短くしたい場合には、オープンソースのアイコンフォントであればアイコンフォントのファイルをカスタム作成することでこの問題は回避することが出来ます。したがって、オープンソースのアイコンフォンを利用すれば無駄にアイコンをロードしないように出来ます。

アイコンが単色になる問題

アイコンフォントはフォントである以上一つのアイコンに複数の色を指定できません。アイコンをカラフルにしなければいけないという要件でもなければ、大した問題ではないかもしれません。

この問題を少しばかり軽減するテクニックはありますので紹介します。

ドロップシャドー
テキストと同様にスタイルシートでドロップシャドーのエフェクトをかける事ができます。

アイコンフォントの対応環境

アイコンフォントはOSのデフォルトフォントではないので外部からロードすることになります。 Web ブラウザでは Web フォントとしてサーバーからロードすることが出来ます。ブラウザ毎の対応状況はWebフォントのブラウザ対応で確認できます。JavaFX のようなリッチクライアントの場合はフォントファイルをアプリケーションとともに配布してローカルからロードすることも、Web フォントとしてロードすることも可能です。

アイコンフォントの評価について

アイコンフォントのイメージについての品質は次の観点から客観的に評価すべきでしょう。

  • コンセプトが伝わる
  • サイズが揃っている

アイコンフォントのイメージの比較

アイコンを実際に使用する際には同じカテゴリのアイコンを組み合わせて使用することが多いので利用頻度の高いアイコンのイメージを次のカテゴリ毎にFont Awsome と ioniconsを比較してみます(IcoMoonについては割愛します)。いずれのフォントも実際のレンダリング結果からき実用レベルの品質であることが分かります。
