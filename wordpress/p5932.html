Snow Flower Look and Feel (LnF)

Snow Flower は JavaFX の為のルックアンドフィールです。OS に依存せずクロスプラットフォームで全く同じ見た目となるようにデザインされています。雪面に咲く花をモチーフにデザインされています。美しい見えた目と使いやすさを両立しホビーユースからビジネスユースまで幅広くサポートします。

Snow Flower IIO (Image IO)

Snow Flower IIO は JavaFX IIO の拡張技術です。標準対応の形式に加えて、TIFF, JPEG2000, ICO 等の形式を JavaFX API から透過的に扱う事が出来ます。AWT/ImageIO 経由の方法と比較して並列性とメモリー効率が大幅に向上します。

YOSBITS VDOM (Virtual DOM)

YOSBITS Virtual DOM 技術は Java の JavaScript エンジンである Nashorn に DOM API を追加します。この技術により、DOMに依存する JavaScript ライブラリを Java 上で動作させる事ができます。Webブラウザに依存する可視化技術をブラウザに依存せず Java 技術と統合可能になります。Virtual DOM の更新は画面更新を伴わないのでブラウザよりも高速に動作します。

YOSBITS SVG2D (SVG Graphics 2D)

Graphics2D インタフェースを実装した 高速で軽量なSVG のレンダラです。SVG2Dの出力するSVGは局所的な最適化だけなので、SVGOと組み合わせることで更に最適化されたSVGを出力にする事ができます。java.awt の Graphics API をベースに実装されたライブラリのグラフィック出力を Web に適した SVG 形式に変換出力することが出来ます。Graphics2D APIのカバー範囲は広く多くのオープンソースライブラリに対応しています。

YOSBITS SVGO(SVG Optimizer)

YOSBITS SVGO は Java 実装の高速なSVGの最適化エンジンです。利用用途の負荷に合わせて各種最適化オプションをスイッチすることができます。
