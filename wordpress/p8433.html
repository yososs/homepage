Snowflower Diff は比較とマージのための非常に強力なツールです。 あらゆる比較シーンに適した分かりやすいグラフィカル環境で 差異を簡単に素早く見つけることができます。

2つのファイルを比較して差異を確認したい機会はテキストに限らずよくあります。

  • 画像の比較

  • オフィス文書の比較

  • バイナリファイルの比較

  • メタ情報の比較

どこを追加してどこを変更したのか、どこが削除されたのかを比較ツールを使わずに目で探すのはとても大変です。 比較作業はコンピュータに任せて有意義な作業に注力すべきです。

Snowflower Diff はこれら多くの比較の機会で使用できます。 あなたのプロジェクトで活用すれば比較とマージ作業はこれまでとは段違いにスムーズになります。

比較

2つのファイルあるいはフォルダーをアプリケーションにドラッグするだけで、 すぐに比較が始められます。フォルダー比較の差異一覧からクリック操作でファイル比較をシームレスに開くことができます。

2つのファイルの違いを見つける方法にはテキスト、イメージ、バイナリ、メタモードの比較モードがあります。 アプリケーションは比較対象のファイルに適した比較モードを自動で選択します。 コンテキストメニューで比較モードを明示的に指定することも可能です。

フォルダー比較

フォルダ比較モードは2つのフォルダーを再帰的にたどり ファイル名が一致するファイルを比較して違いを一覧表示します。 変更されたファイルまたは一方にのみ存在するファイルが表示されます。 差異は追加、削除、変更に分類され色が付けられハイライトで表示されます。

記号の意味
-

左側にのみ存在するファイル

+

右側にのみ存在するファイル

*

異なる内容の同名ファイル

フォルダーの比較操作は選択したフォルダーに多くのファイルがある場合にはレスポンスが遅くなる可能性があります。

テキスト比較

テキストファイル比較モードは2つのテキストファイルを素早く見やすく比較することが可能です。 そして高度な編集をサポートするテキストエディタでインタラクティブにマージ作業が可能です。 テキストエディターはマルチカーソル、シンタックスハイライトをサポートしています。

２つのテキストファイル間の差異（追加、削除、変更）を色分けで視覚的に表示します。 行と文字単位の２つの段階で色分けされ、素早く差異を見つけることが可能です。

テキスト比較モードでは次の比較オプションがあります。

空白を無視

このオプションを有効にするとすべての空白文字を無視します。 また、改行コードの違い（LFとCRLF）が無視されます。

テキスト比較モードでは次の表示オプションがあります。

並べて表示

並べて表示モードは2つのファイル違いを横に並べて表示する。

ユニファイド

ユニファイド表示モードは2つのファイルの違いを より少量で読みやすく表示する形式です。

テキストファイルの比較操作は選択したファイルのサイズが大きい場合には レスポンスが遅くなる可能性があります。

バイナリ比較

バイナリ比較モードは16進数でデータを比較します。 2つのファイルのいずれかがバイナリであるとアプリケーションが判断した場合か、 コンテキストメニューで明示的にバイナリ比較モードで開く場合に バイナリ比較ビューで開きます。 バイナリ比較モードでは読み取り専用モードになります。

イメージ比較

イメージ比較モードは高度な画像比較によって差異のあるか所をハイライト表示します。 写真の修正箇所を見つけたり、イラストの差異のチェックに役立ちます。

イメージ比較モードには次の２つの表示オプションがあります。

横に並べる(Side by Side)

横に並べて表示する画像比較方法で自動的に差異を検出します。 単純なピクセル単位での比較とは異なりオブジェクトの移動を検出します。 JPEG画像に含まれる僅かな不可逆圧縮ノイズは無視します。

重ねる(Stacked)

２つの画像を重ねて表示します。 ユーザはスライダー操作で透過率が変更でき 変化のある位置を見つけることができます。

「横に並べる」では自動で画像の差異を報告します。 「重ねる」は自動の再検出で差異が見つからない場合に 簡単な操作でユーザ自身で差異を発見するのに役立ちます。

次の画像フォーマットをサポートしています。

  • BMP

  • GIF

  • JPEG

  • PNG

  • SVG

  • TIFF

  • WBMP

オフィス文書の比較

オフィス文書の比較モードはテキスト展開してテキストモードと同じインタフェースで比較します。 テキストエディタは編集不可のモードになります。

次のオフィス文書フォーマットをサポートしています。

  • Microsoft Excel

  • Microsoft PowerPoint

  • Microsoft Word

  • Open Document

  • PDF

  • RTF

メタ情報の比較

メタ情報の比較モードは２つのファイルのメタ属性を比較して差異のあるか所をハイライト表示します。

次の画像や動画等のファイルフォーマットをサポートしています。

画像フォーマット

  • ARW

  • BMP

  • CR2

  • CRW

  • DNG

  • GIF

  • ICO

  • JPEG

  • NEF

  • ORF

  • PCX

  • PNG

  • PSD

  • RAF

  • RAW

  • RW2

  • RWL

  • SRW

  • TIFF

  • WebP

  • X3F

動画フォーマット

  • MOV

  • MP4

  • M4V

  • 3G2

  • 3GP

  • 3GP

エクスポート

選択しているタブがテキスト比較モードの場合、 次の２つの形式に差異情報をエクスポートすることができます。

  • Unified Diff

  • HTML

Unified Diff 形式は広く使用されている Unix diff スタイルです。 出力ファイルはpatch コマンドへの入力として使えます。
